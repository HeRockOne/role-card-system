# 角色建模系统 Role Card System

职场沟通 / 向上管理建模的方法论 + 落地工具。

用「角色卡」把职场关系建模成可维护的卡片体系：**公司（总卡=老板/CEO）→ 部门（分卡=总监）→ 具体的人（实例卡）**，三层继承、子层覆盖父层。每张卡带**数字职级 1-10**（1=老板，数字越大职级越低），组织图按职级从上到下分行；一套十维框架统一描述所有的上下级相处模式。

## 功能（v1.4）

- **🏢 组织结构图**：无限画布 + 自动布局（父节点居中于子节点上方）、SVG 连线、拖拽平移 / 滚轮缩放、公司下拉切换、点击节点看十维详情、搜索高亮。
- **📁 层级流转链**：点卡片向下钻，面包屑每一环可点向上回，上下流转闭环。
- **🌳 树状总览**：按职级层级展示，节点可折叠/展开，详情按钮直达。
- **职级模型**：每张卡有数字职级 1-10（1=老板/CEO，数越大职级越低），编辑时下拉选择；选 1 级自动转总卡；父卡不限类型、不限职级（降级可调整），只排除自己。
- **三层继承**：岗位卡存 `dims`（共性可继承）、个人卡存 `patches`（个人补丁），改动上层下游全自动获得。
- **十维人话翻译**：每个维度一句提问 + 示例，编辑时继承预告实时提示。
- **浅色/夜间主题 + 移动端适配 + IndexedDB 存储**。

## 核心建模思路

1. **十维框架**：每一维都是一句人话问题，例如「权杖边界」= 你管什么、不越谁的线；「恐惧清单」= 上司最怕出什么乱子。
2. **三层继承**：总卡写公司人人通用的共性 → 分卡写某一部门总监的职责差异 → 实例卡只写某个具体人的补丁差异。改一层，下游全部自动获得。
3. **编辑即建模**：新建/编辑实例卡时，每个维度实时显示「✏️ 本卡已在此定义(将覆盖父层) / 🌳 继承自 [来源] / 🈳 未定义」，照着继承预告填差异即可，不用背任何框架。

## 技术说明

- 解析引擎：`resolveCard` 沿 `parentId` 链合并（子覆盖父），`sourceOf` 溯源每个维度的显式定义来源，`chainOf` 输出根→叶链路。
- 数据模型：统一 `cards` 数组（v1.4）；岗位卡存 `dims`、个人卡存 `patches`（差异补丁，清空=撤销覆盖），类型由 patches/level 推导。
- 存储层：IndexedDB（库 `rcs-db`，键 `rcs_cards_v14`）优先，不可用自动降级 localStorage；启动时自动迁移旧版（v1.3 / v1.2）数据。
